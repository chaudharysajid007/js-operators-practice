# JavaScript Fundamentals: Operators Practice

A hands-on JavaScript exercise designed to demonstrate and test core JavaScript operators, including Arithmetic, Assignment, and Comparison operations.

## 📌 Features Covered

- **Arithmetic Operators:** Addition (`+`), Subtraction (`-`), Multiplication (`*`), Division (`/`), Remainder (`%`), and Exponentiation (`**`).
- **Assignment Operators:** Simple (`=`), Addition (`+=`), Subtraction (`-=`), Multiplication (`*=`), and Division (`/=`).
- **Comparison Operators:** Loose vs. Strict Equality (`==` vs `===`), Inequality (`!=`, `!==`), and Relational comparison (`>`, `<`, `>=`, `<=`).
